# Differential-Expression-Analysis

A streamlined pipeline for differential gene expression analysis of bulk RNA-seq data using **DESeq2**. This repository is designed to analyze filtered transcript- and gene-level count matrices generated by a Nextflow RNA-seq pipeline and identify differentially expressed genes between experimental conditions.

## Repository Structure

```
Differential-Expression-Analysis/
├── Step1_DEGAnalysis.ipynb   # Load, organize, and prepare count matrices
├── Step2_DEGAnalysis2.r      # Run DESeq2 differential expression analysis
├── helpers/                  # Helper functions for data processing
└── plotting/                 # Functions for visualization
```

## Workflow

1. **Step1_DEGAnalysis.ipynb**

   * Import filtered transcript and gene count matrices from the Nextflow pipeline.
   * Format and prepare count data and sample metadata for downstream analysis.

2. **Step2_DEGAnalysis2.r**

   * Perform differential expression analysis with **DESeq2**.
   * Generate statistical results including log₂ fold changes, p-values, and adjusted p-values.

## Requirements

* R (with **DESeq2** installed)
* Jupyter Notebook (Python)

## Reference

Love, M. I., Huber, W., & Anders, S. (2014). *Moderated estimation of fold change and dispersion for RNA-seq data with DESeq2*. **Genome Biology**, 15(12), 550. https://doi.org/10.1186/s13059-014-0550-8
